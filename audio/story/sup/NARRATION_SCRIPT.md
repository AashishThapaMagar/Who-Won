# Supreme's story: narration script

Record each line as the file named on the left and drop it in this folder
(`audio/story/sup/`). `.ogg`, `.wav` or `.mp3` all work. A recorded line plays with
its text and the scene moves on when it ends; lines without a file stay silent.

**Who reads what:** NARRATOR lines are yours. SUPREME lines are Supreme's.
Lines by the other fighters are optional (leave them silent, or get friends to read them).
